SANDBOX

Full workstation setup (binaries, skill, and Codex MCP registration):

  curl -fsSL https://tools.yshubham.com/sandbox/setup.sh | sh

Install only the Sandbox skill globally into every supported agent:

  npx skills add bas3line/rool-repo --skill sandbox-platform --agent '*' --global --yes

Inspect all skills before installing:

  npx skills add bas3line/rool-repo --list

Skill source: https://github.com/bas3line/rool-repo/tree/main/skills/sandbox-platform


WATCHMAN

Install the CLI:

  curl -fsSL https://tools.yshubham.com/watchman/install.sh | sh
  watchman version

Install the Watchman skill globally into every supported agent:

  npx skills add bas3line/rool-repo --skill watchman --agent '*' --global --yes

Inspect the skill before installing:

  npx skills add bas3line/rool-repo --list

Update an installed skill:

  npx skills update watchman --global --yes

CLI source:   https://github.com/bas3line/watchman
Skill source: https://github.com/bas3line/rool-repo/tree/main/skills/watchman

The hosted CLI and complete agent skill both target Rust Watchman v0.8.3.
